# دعوة خطوبة فاخرة — الدكتور عبدالقادر & المهندسة نور

موقع دعوة خطوبة تفاعلي فاخر، مبني بـ HTML و CSS و JavaScript خالص — بدون أي إطار عمل أو أدوات بناء.
يعمل بالكامل دون اتصال بالإنترنت، باستثناء زر خرائط جوجل وزر واتساب.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر

ارفع محتويات المجلد كما هو إلى أي استضافة ثابتة (Netlify / Vercel / GitHub Pages / استضافة عادية).
لا حاجة لأي خطوة بناء.

## هيكل المشروع

```
index.html          الصفحة الكاملة (RTL / عربي)
style.css           نظام التصميم والحركات
script.js           التفاعلات: التحميل، الجسيمات، العد التنازلي، الموسيقى، الكشف عند التمرير
fonts/              خطوط محلية (Aref Ruqaa, Amiri, Reem Kufi, Cormorant Garamond) + fonts.css
images/             الزخارف الذهبية، الفاصل الوردي، خلفية الرخام
icons/              أيقونات SVG (تقويم، موقع، منزل، سيارة، قرآن، واتساب، موسيقى، أيقونة الموقع)
music/              luxury-theme.mp3 — موسيقى بيانو ووتريات هادئة بدون كلمات، تعمل بشكل متصل
assets/             مجلد للإضافات المستقبلية
README.md           هذا الملف
```

## التخصيص السريع

| ماذا | أين |
|---|---|
| تاريخ العد التنازلي | `script.js` → `EVENT_DATE` |
| رقم واتساب | `index.html` → رابط `#waBtn` (بصيغة دولية `9647702282219`) |
| رابط الخريطة | `index.html` → رابط قسم `#location` |
| الألوان والذهب | `style.css` → متغيّرات `:root` |
| الموسيقى | استبدل `music/luxury-theme.mp3` بملف آخر بنفس الاسم |

## ملاحظات تقنية

- تصميم متجاوب بالكامل: iPhone / Android / تابلت / سطح المكتب.
- دعم `prefers-reduced-motion` لتقليل الحركة تلقائياً.
- الموسيقى لا تعمل إلا بعد تفاعل المستخدم (سياسة المتصفحات) — تبدأ عند الضغط على «فتح الدعوة».
- الخطوط محلية، لذا لا يوجد أي طلب لخوادم خارجية.
